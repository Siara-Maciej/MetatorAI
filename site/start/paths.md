# Choose your path

Three ways in. Each is a short read, and each ends in something you can run today.

## I write code with agents

You want a feature built the way your codebase already works, and you want to stay in control without babysitting every step.

1. [Quick start](./quick-start.md): set MetatorAI up in your repository in fifteen minutes.
2. [Feature (W1)](../work/feature.md): a run from task to pull request, with the plan gate and the push approval.
3. [Inbox and decisions](../work/inbox.md): answer every question from one queue, without opening the session.
4. [Sessions and terminals](../work/sessions.md): when you want to see the terminal, or run several sessions side by side.

The concepts you will meet: [Run](../concepts/run.md), [Gate and approvals](../concepts/gate.md), [Session](../concepts/session.md).

## I own the platform

You want the team's conventions enforced by tools, the same agents on every AI host, and gates in CI.

1. [Installation](./installation.md) and `metator setup`: the canon installed, the host files generated, the gates configured from evidence.
2. [Write and enforce rules](../knowledge/rules.md): rules with an id, promoted from guidance to tool-enforced.
3. [Agents and skills](../knowledge/agents.md): one canonical definition, generated for Copilot, Claude Code and OpenCode.
4. [Quality gates and CI](../knowledge/gates-ci.md) and [Keep knowledge true](../knowledge/truth.md): `meta check-all` in CI.

The concepts you will meet: [Canon](../concepts/canon.md), [Host](../concepts/host.md), [Workflow](../concepts/workflow.md).

## I review code

You want review comments that are right, with the evidence attached, and silence when there is nothing to say.

1. [Review (W4, W5)](../work/review.md): a PR review in chat, a self-review before the PR, and the headless review in CI.
2. [Finding](../concepts/finding.md): what a finding must carry, and how the verifier tries to refute it.
3. [Security and governance](../reference/security.md): what is enforced, logged and approved.

## Not sure?

Read [Why MetatorAI](./why.md) and [How it works](./how-it-works.md), then come back here.
